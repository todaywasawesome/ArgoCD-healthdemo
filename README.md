# ArgoCD-healthdemo

Live demo for the talk "Argo CD's health checks are your secret weapon to CD nirvana".
kind cluster + **Argo CD v3.6.0** (pinned: `manifests/argocd-install-v3.6.0.yaml`) + four custom
health checks applied live. Full runbook with real output and screenshots: [`demo/RUNBOOK.md`](demo/RUNBOOK.md).

| Path | What |
|---|---|
| `kind/cluster.yaml` | 1 control plane + 1 worker, pinned node image, no load balancer |
| `argocd-config/health/*.lua` | one health check per file; key = file name |
| `argocd-config/argocd-cm.yaml` | assembled checks (generated by `scripts/build-cm.sh`, used by tests) |
| `apps/` | manifests for `config-demo`, `widget-demo`, `wave-demo`, `lb-demo` |
| `argocd-apps/` | the Applications (track branch `demo-live`) |
| `crds/widget-crd.yaml` | `Widget` CRD (no controller; `scripts/set-widget-status.sh` plays it) |
| `fixtures/` | offline test fixtures + expected status |

## Setup

```
GIT_TOKEN file in the repo root (git-ignored) with a token that can push to this repo
kind create cluster --config kind/cluster.yaml
scripts/load-images.sh
kubectl create ns argocd
kubectl apply -n argocd --server-side --force-conflicts -f manifests/argocd-install-v3.6.0.yaml
scripts/port-forward.sh
# log in, then write .demo-credentials (ARGOCD_ADMIN_USER/PASSWORD, DEMO_AGENT_TOKEN); see RUNBOOK
scripts/reset.sh && scripts/preflight.sh
```

## Scripts

`reset.sh` opening state · `run-demos.sh` all demos with assertions · `test-health.sh` offline
checks · `preflight.sh` readiness · `apply-config.sh [check]` add checks live · `health.sh <app>`
per-resource health messages · `set-demo-state.sh ok|broken` · `set-widget-status.sh` ·
`register-mcp.sh` Argo CD MCP server for Claude Code · `secret-check.sh` run before every commit.

Git: `reset.sh` force-pushes `demo-build` → `demo-live`; live demo commits land on `demo-live`
(unsigned, throwaway). Never on `main`.
